🌟 Poketstar POS

Enterprise Point-of-Sale System for East Africa

v1.0 Production Ready

📋 Overview

Poketstar POS is a comprehensive enterprise-grade point-of-sale system designed specifically for retail businesses in East Africa. Built with modern web technologies, it provides real-time inventory management, secure payment processing, and detailed sales analytics.

✓ Complete Documentation Available: A comprehensive HTML and Form summary document has been created. See HTML_FORMS_SUMMARY.md for detailed technical documentation.

✨ Key Features

💳 Sales Terminal

Real-time checkout with barcode scanning, autocomplete product search, and instant inventory updates.

📦 Inventory Management

Track stock levels, manage product categories, monitor low-stock alerts, and optimize reorder points.

💰 Multi-Payment Support

Accept Cash, M-Pesa, and Card payments with integrated payment gateways and secure transaction logging.

📊 Analytics & Reports

Comprehensive sales reports, revenue tracking, product performance analytics, and export capabilities.

🌓 Dark/Light Mode

User-friendly interface with theme switching for different lighting conditions and personal preferences.

🎨 Customizable Branding

Multiple logo options, theme customization, and branding settings for business personalization.

🔧 Technical Stack

HTML5 CSS3 JavaScript (ES6+) localStorage API CSS Grid & Flexbox Responsive Design

The application is built with vanilla HTML, CSS, and JavaScript—no external frameworks required. It uses browser localStorage for data persistence and supports both online and offline operation modes.

💾 Data Management

Currently uses browser localStorage for data persistence. Products and sales records are stored locally and can be exported as JSON.

localStorage.getItem('ps_products') // Product inventory localStorage.getItem('ps_sales') // Sales history

Future Enhancement: Planned integration with backend database (MongoDB or PostgreSQL) for multi-location support and centralized reporting.

📖 Getting Started

To use the Poketstar POS system:

  1. Open in Browser: Simply open this HTML file in a modern web browser (Chrome, Firefox, Safari, Edge)
  2. Add Products: Use the Admin modal to add products with name, barcode, price, and quantity
  3. Process Sales: Scan barcodes or search for products, add to cart, and complete transactions
  4. Manage Inventory: Monitor stock levels, receive low-stock alerts, and update quantities
  5. View Reports: Access sales analytics, revenue reports, and transaction history
  6. Export Data: Download sales records in JSON format for backup or analysis

📋 System Requirements

Browser
