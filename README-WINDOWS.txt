Welcome to Poket Star POS for Windows!

PACKAGE CONTENTS:
-----------------
1. PoketStar-POS-32bit.exe   -> Standalone 32-bit (x86 Universal) executable for all Windows PCs.
2. PoketStar-POS-64bit.exe   -> Standalone 64-bit (x64 Optimized) executable for modern 64-bit PCs.
3. Start-POS-Desktop.bat     -> One-click smart launcher that detects your PC architecture.
4. index.html                -> Offline-first POS application core (100% offline with IndexedDB).
5. products.json             -> Local database of 1,629 inventory catalog products.

HOW TO RUN ON WINDOWS:
----------------------
Option A (Easiest):
  Double-click "PoketStar-POS-32bit.exe" or "PoketStar-POS-64bit.exe".
  The POS terminal engine will start and open your counter window automatically.

Option B (Smart Launcher):
  Double-click "Start-POS-Desktop.bat". It will select the best architecture for your PC.

Option C (Direct Browser / No Installation):
  Double-click "index.html" in Google Chrome or Microsoft Edge.
  Everything runs 100% offline on your machine with direct thermal receipt printing!

WINDOWS SMARTSCREEN NOTE:
-------------------------
If Windows displays "Windows protected your PC":
1. Click "More info".
2. Click "Run anyway".
This occurs on portable retail executables that are distributed directly.
